# 日記・タイムライン

ボタンを押すだけで「何時に何をしたか」が残る、自分だけの1日のタイムライン。
スマホのブラウザで開いて、ホーム画面に入れて使います。

- 記録は**その端末の中だけ**(IndexedDB)。よそのサイトから何も読み込まず、解析の道具も入っていません。
- 電波がなくても開けます。
- いくつかの端末で使いたいときだけ、グーグルドライブで同期できます(中身は合言葉の鍵をかけてから置くので、Google にも読めません)。

## できること

- 最初に「あなたの毎日に近いのは?」(会社員・学生・家のこと中心・在宅/フリーランス・シフト勤務・自分で作る)を選ぶと、それに合ったボタンが並ぶ。あとから「ボタン設定」→「ひな形から選び直す」でも変えられる
- ボタンで記録: 起床・出発・到着・出社・退社・帰宅・就寝・食事・入浴・休憩・読書・用事 など。タブで分かれていて、「ボタン設定」で足す・名前と絵を変える・並べ替える・消す
- 時間の長さ: 就寝→起床で睡眠、出社→退社で勤務、出発→到着で移動…のように、組で自動的に終わる。続いているものは下の帯に出る
- 移動手段と乗りかえ(徒歩・電車・バス・車・自転車 など)
- 「書く」で長い文章と写真(写真は小さくして、撮影場所などの情報は消してからしまう)
- 録音(声は端末の中だけ)
- 遊び: 外食・カフェ・映画・カラオケ・散歩・旅行・飲み会・推し活・観戦・温泉。終わったら「楽しかった度」(😞〜🤩)を付けられる。ボタン設定の「候補から足す」に、ジャズ・キャンプ・登山・釣り・スキー・料理など60近くの候補。だれと(友だち・家族など)も付けられる
- 1年前の今日: 去年の同じ日の記録や写真をそっと出す
- ふりかえり: いちばん楽しかった日、続けた日数のバッジ、登録した場所のスタンプラリー
- 体調(気分・体温・体重・血圧・睡眠・お薬など)・お通じ・天気
- 場所(押したときに測る。名前は自分で登録。住所の検索はしない)
- 押し忘れたときは「本当の時刻にさかのぼる」
- 前の日を見る・直す。直すとつながっている記録の時刻も一緒に動く
- 今日の暦(六曜・旧暦・二十四節気・月・祝日・何の日 など)、潮位表の読み込み
- 統計(1日の円グラフ・勤務時間・移動手段ごと・通勤・睡眠・食事)
- バックアップ: 全部を1つのファイルに書き出す/読み込む

## 使い方 A: 公開している場所を開く

配った人から教えてもらった URL をスマホで開き、ホーム画面に入れます。

- **iPhone**: Safari で開く →「共有」→「ホーム画面に追加」。ホーム画面に入れないと、しばらく使わないうちに記録が消されることがあります。
- **Android**: Chrome で開く → メニュー →「ホーム画面に追加」(または「アプリをインストール」)。

同じ URL を使っていても、記録は**それぞれの人の端末の中**にあり、ほかの人からは見えません。

## 使い方 B: 自分で置く(この zip)

中身はふつうのファイル(HTML・CSS・JavaScript)だけです。組み立て(ビルド)はいりません。
**https** で配れる場所ならどこでも動きます(位置を測る・ホーム画面に入れるのに https が要ります)。

- **GitHub Pages**: 新しいリポジトリにこの zip の中身を全部置き、Settings → Pages で公開。
- **ほかの静的なホスティング**(Netlify・Cloudflare Pages など): フォルダをそのまま置くだけ。
- **パソコンで試すだけ**: このフォルダで `python -m http.server 8000` → `http://localhost:8000/` を開く。

フォルダの中のどこに置いても動きます(ファイルの指し方はすべて `./` から)。

## 同期(いくつかの端末で使うとき)

使う人それぞれが、自分の Google アカウントで「クライアント ID」を作って入れます。手順は `setup-google.html`(アプリの「バックアップ」→「グーグルドライブで同期」の欄からも開けます)。

- 合言葉を忘れると、ドライブに置いた分は誰にも開けません。
- ドライブには「アプリ専用の隠しフォルダ」だけを使います(ふつうのドライブのファイルには触りません)。

## 大事なこと

- ときどき「バックアップ」→「ファイルに書き出す」で控えを取ってください。端末をなくしたり、ブラウザのデータを消したりすると、記録も消えます。
- 体調の記録は自分の控えのためのもので、病気かどうかの判断はしません。
